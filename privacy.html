Privacy policy

Last updated: September 29, 2026.

rclone Kwozi is a personal OAuth client for rclone, used only by its owner to upload his own videos to his own Google Drive. This policy explains what it does with Google user data.

What it accesses

With the owner's consent, rclone uses the Google Drive API (scope https://www.googleapis.com/auth/drive) to list folders and to upload, update and read files in the owner's Google Drive. It does not access any other Google data.

How the data is used and stored

rclone runs on the owner's own computer. The access token Google issues is stored only in rclone's configuration file on that computer. No data is sent to, or stored on, any server other than Google's own.

Sharing

Google user data is not shared with, sold to, or transferred to anyone. It is not used for advertising, and it is not used to develop, improve or train artificial intelligence or machine learning models.

Limited Use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
